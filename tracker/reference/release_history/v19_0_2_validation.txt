NIH TRACKER v19.0.2 VALIDATION REPORT
=====================================

Validation date: 2026-09-29.

Purpose
-------
v19.0.2 is a bounded guided-review state hotfix. It corrects a state in which
later model recommendations were reopened for approval even though durable,
non-pending human identifier adjudications already existed for the same stable
review keys. In the reported production state, all five current queue families
had zero pending rows, while two identifier adjudications remained unapplied.

Behavioral correction
---------------------
- A current operational human adjudication now takes precedence over any later
  provider recommendation for the same stable review_key.
- The later recommendation remains in the recommendation inventory for audit.
- It does not become an approval blocker and cannot displace the human decision.
- A genuinely new recommendation still reopens a terminally superseded or
  quarantined item when no operational adjudication exists.
- Explicit human editing or reopening remains available through manual review.
- No card, recommendation, approval, or adjudication row is rewritten merely by
  computing the corrected status.

Expected reported-state result
------------------------------
The regression fixture reproduces the material state:

- zero pending candidate rows;
- a newer provider recommendation after a terminal historical approval;
- a current non-pending identifier adjudication for the same review key;
- one operational row awaiting application.

The corrected status is READY_TO_FINALIZE, with zero imported items awaiting
approval and one recommendation item reported as covered by a current decision.
The production case with two such rows therefore proceeds directly to validation
and application of the two identifier adjudications.

Notebook correction
-------------------
- Section 3 is now a state-aware next-action panel.
- APPROVAL_REQUIRED shows a single approval button.
- REVIEW_REQUIRED shows only nonempty candidate-queue controls.
- READY_TO_FINALIZE hides empty queue dropdowns and directs the reviewer to the
  finalization control.
- COMPLETE directs the reviewer to the main pipeline.
- The dashboard reports later recommendations already covered by current human
  decisions.
- The import section remains available for new web-review result files but no
  longer duplicates the approval control.

-------------------

4. The operational adjudication remains pending for the guarded apply step.
5. The v19 review notebook contains the state-aware next-action panel and hides
